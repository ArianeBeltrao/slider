# Desafio Xlow - Slider

# Sobre o projeto

Este projeto é um desafio técnico para uma vaga de trabalho.
O objetivo é desenvolver um Slider de imagens em React que possui rolagem infinita, rolagem automatica e
também contenha setas para navegar entre as imagens a esquerda e a direita da imagem atual.
Além disso, o Slider também deve conter bolinhas clicáveis para navegar entre as imagens.
